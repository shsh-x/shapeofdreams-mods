[h1]Spell Blocker[/h1]

Locks your skill slots so you don't accidentally cast them. Or so you don't obliterate your teammates during confusion debuffs. Whatever reason you can come up with is good enough to try it.

Press key to lock, press again to unlock. That's literally it.

[h2]Default Keys[/h2]
[list]
[*] [b]Alt + 1..4[/b] : Lock / unlock skill slots 1 to 4
[*] [b]Alt + 5[/b] : Lock dash
[*] [b]Alt + 6[/b] : Lock identity memory (also stops its passives like chain procs)
[*] [b]Alt + 0[/b] : Unlock everything
[/list]

Keys can be rebound in [b]Settings -> Mods -> Spell Blocker[/b] (or you can turn off the Alt requirement there if you prefer).

[h2]Multiplayer[/h2]
Host needs to have this installed for it to work. In solo play you are the host anyway.
And this is NOT the host-only mod - guests need to install it too (if they need it at all).
